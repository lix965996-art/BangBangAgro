# 帮帮农 Android App - 快速开始指南

## 已完成的工作

我已经为你创建了一个完整的安卓 App 套壳项目，所有文件都在 `android-app` 文件夹中，**不会影响你原来的任何代码**。

## 下一步：构建 APK

### 前置条件

你需要安装以下软件才能构建 APK：

1. **Java JDK 11+**
   - 下载：https://adoptium.net/
   - 安装后设置 JAVA_HOME 环境变量

2. **Android Studio**
   - 下载：https://developer.android.com/studio
   - 安装时勾选 Android SDK

### 设置 Android SDK 路径

**方式一：设置环境变量（推荐）**

1. 打开系统环境变量设置
2. 添加新的系统变量：
   - 变量名：`ANDROID_HOME`
   - 变量值：`C:\Users\你的用户名\AppData\Local\Android\Sdk`
3. 编辑 Path 变量，添加：
   - `%ANDROID_HOME%\platform-tools`
   - `%ANDROID_HOME%\tools`

**方式二：修改 local.properties**

编辑 `android-app/android/local.properties` 文件：

```properties
sdk.dir=C\:\\Users\\你的用户名\\AppData\\Local\\Android\\Sdk
```

### 构建 APK

**方式一：双击运行脚本（最简单）**

1. 双击 `build.bat`
2. 等待构建完成
3. APK 文件在 `android/app/build/outputs/apk/debug/app-debug.apk`

**方式二：使用命令行**

```bash
# 进入 android-app 目录
cd android-app

# 同步 Web 资源
npx cap sync android

# 进入 android 目录
cd android

# 构建 debug APK
gradlew assembleDebug
```

**方式三：使用 Android Studio**

1. 打开 Android Studio
2. 选择 "Open an existing Android Studio project"
3. 导航到 `android-app/android` 文件夹
4. 等待 Gradle 同步完成
5. 点击 Build > Build Bundle(s) / APK(s) > Build APK(s)

当你修改了 Vue 前端代码后：

```bash

update-web.bat

# 方式二：手动操作

cd ../android-app

```

## 常见问题

### Q1: 构建失败，提示"SDK location not found"

**A:** 需要设置 Android SDK 路径，参考上面的"设置 Android SDK 路径"部分。

### Q2: 构建失败，提示"Could not find tools.jar"

**A:** 需要安装 JDK 并设置 JAVA_HOME 环境变量。

### Q3: App 安装后打开白屏

**A:** 可能的原因：
- Vue 项目的 publicPath 设置不正确
- 网络请求失败（后端服务未启动）
- 资源文件路径错误

### Q4: 网络请求失败

**A:** 检查：
- 手机和服务器是否在同一网络
- 服务器防火墙是否开放端口
- API 地址是否正确

### Q5: 如何修改 App 名称和图标？

**A:** 
- App 名称：编辑 `android/app/src/main/res/values/strings.xml`
- App 图标：替换 `android/app/src/main/res/mipmap-*` 文件夹中的图标

## 技术说明

### 这是什么？

这是一个**套壳 App**，原理是：
1. 把你的 Vue 网页代码打包到一个 Android WebView 中
2. 用户打开 App 时，实际上是在看一个全屏的网页
3. 通过 Capacitor 桥接，可以调用一些原生功能（如摄像头、GPS）

### 优点

- ✅ 开发速度快（1-2 周）
- ✅ 代码复用率高（90%+）
- ✅ 跨平台（Android + iOS）
- ✅ 维护成本低

### 缺点

- ❌ 性能比原生 App 慢
- ❌ 复杂动画可能卡顿
- ❌ 用户体验不如原生

## 下一步建议
