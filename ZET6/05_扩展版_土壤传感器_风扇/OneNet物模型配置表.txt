OneNet 物模型配置表

产品ID：
yN8ZASFo9d

设备名：
d1

固件上报 Topic：
$sys/yN8ZASFo9d/d1/thing/property/post

固件上报格式示例：
{
  "id": "123",
  "params": {
    "temp": { "value": 30 },
    "humi": { "value": 60 },
    "soil": { "value": 45 },
    "led": { "value": false },
    "fan": { "value": true },
    "buzzer": { "value": false }
  }
}

需要添加的物模型属性：

1. 标识符：temp
   功能名称：空气温度
   数据类型：整数型 / int
   读写类型：只读
   取值范围：-40 到 125
   单位：℃
   说明：DHT11 温度

2. 标识符：humi
   功能名称：空气湿度
   数据类型：整数型 / int
   读写类型：只读
   取值范围：0 到 100
   单位：%
   说明：DHT11 湿度

3. 标识符：soil
   功能名称：土壤湿度
   数据类型：整数型 / int
   读写类型：只读
   取值范围：0 到 100
   单位：%
   说明：PA4 读取土壤传感器 AO 后换算

4. 标识符：led
   功能名称：补光灯
   数据类型：布尔型 / bool
   读写类型：读写
   取值范围：true / false
   单位：无
   说明：OneNet 可以下发控制

5. 标识符：fan
   功能名称：风扇状态
   数据类型：布尔型 / bool
   读写类型：只读
   取值范围：true / false
   单位：无
   说明：STM32 根据温度自动控制

6. 标识符：buzzer
   功能名称：蜂鸣器状态
   数据类型：布尔型 / bool
   读写类型：只读
   取值范围：true / false
   单位：无
   说明：STM32 根据高温或土壤过干自动报警

OneNet 页面操作：

1. 进入 OneNet 控制台
2. 进入 设备接入与管理
3. 进入 产品管理
4. 找到产品ID为 yN8ZASFo9d 的产品，点 详情
5. 点 设置物模型
6. 添加上面 6 个属性
7. 点 保存，让物模型生效
8. 回到设备 d1，查看物模型数据是否出现 temp、humi、soil、led、fan、buzzer

注意：
标识符必须完全一样。
不要写成中文。
不要大小写写错。
