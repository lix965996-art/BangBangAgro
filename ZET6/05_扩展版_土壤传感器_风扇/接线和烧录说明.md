# ZET6 土壤传感器和风扇接线说明

## 先记住

接线前先拔掉 USB，断电操作。

所有模块的 `GND` 都要接到 STM32 的 `GND`。

土壤传感器的 `VCC` 接 `3V3`，不要接 `5V`。这样 `AO` 输出最高就是 3.3V，比较安全。

## 这次用到的 STM32 引脚

```text
PA4 = 土壤传感器 AO
PE5 = 风扇 GPIO 控制线
PE6 = 低电平触发蜂鸣器 IN / GPIO 控制线
```

原来 ESP-01S 还是这样接，不要改：

```text
ESP-01S TX -> PA3
ESP-01S RX -> PA2
ESP-01S 3V3 -> 3V3
ESP-01S GND -> GND
ESP-01S EN -> 3V3
```

## 土壤传感器接线

土壤传感器有 `AO`、`DO`、`GND`、`VCC` 四个口。

照着接：

```text
土壤传感器 VCC -> STM32 3V3
土壤传感器 GND -> STM32 GND
土壤传感器 AO  -> STM32 PA4
土壤传感器 DO  -> 先不接
```

板子背面找 `PA4 PA3` 那一行，`PA4` 是土壤传感器用的。`PA3` 已经给 ESP 用了，不要插错。

## 5V 风扇接线

你的风扇有 `VCC`、`GND`、`GPIO` 三个口。

照着接：

```text
风扇 VCC  -> STM32 5V
风扇 GND  -> STM32 GND
风扇 GPIO -> STM32 PE5
```

板子背面左下附近能找到 `PE5 PE4` 那一行，接 `PE5`。

如果你的风扇只是裸风扇，只有红黑黄三根线，黄线不是 GPIO 控制线，而是测速线；这种不能按上面接，需要一个 MOS 管或风扇驱动模块。

## 低电平触发蜂鸣器接线

蜂鸣器如果写着低电平触发，一般会有 `VCC`、`GND`、`IN` 或 `GPIO`。

优先这样接：

```text
蜂鸣器 VCC -> STM32 3V3
蜂鸣器 GND -> STM32 GND
蜂鸣器 IN/GPIO -> STM32 PE6
```

如果接 `3V3` 声音太小，并且你的蜂鸣器模块明确支持 `5V`，可以把 `VCC` 改接 `5V`，但是 `GND` 仍然必须和 STM32 的 `GND` 接一起。

低电平触发的意思：

```text
PE6 输出低电平 -> 蜂鸣器响
PE6 输出高电平 -> 蜂鸣器不响
```

## 自动控制逻辑

程序会读温度和土壤湿度：

```text
温度 >= 30C：开风扇
温度 <= 28C：关风扇

土壤湿度 <= 25%：蜂鸣器报警
温度 >= 35C：蜂鸣器报警
土壤湿度 >= 35% 且 温度 <= 32C：关闭蜂鸣器
```

风扇现在不再由土壤湿度控制。土壤湿度只用于显示、上传和报警。

OLED 显示：

```text
Temp 温度
Humi 湿度
Soil 土壤湿度
Fan  风扇状态
Buzzer 蜂鸣器状态
```

OneNet 上传字段：

```text
temp
humi
soil
led
fan
buzzer
```
